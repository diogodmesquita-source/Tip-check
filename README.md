# Tip Check — PWA

Aplicativo web instalável para iPhone.

## O que faz
- Arraste um screenshot ou escolha uma imagem.
- Faz OCR no navegador.
- Tenta identificar endereço/código postal.
- Consulta um banco local (IndexedDB).
- Se o destino já tiver histórico, mostra a tendência de tip.
- Se for novo, pergunta depois da coleta se houve tip e grava.
- Exporta/importa backup JSON.
- Não inclui a aba Marks & Spencer.
- O banco é local ao dispositivo; o código do app pode ser publicado gratuitamente no GitHub Pages.

## Importante
A tip não é visível no screenshot pré-coleta. Portanto, o app **não adivinha a tip do print**: ele usa o histórico aprendido daquele destino.
