Como funciona 0 registros
O app não tenta ler a tip do print. Ele procura primeiro o Eircode do cliente, porque ele é a identificação mais confiável do destino. Textos do mapa, como parques, bairros, nomes de estradas e pontos de interesse, são ignorados. Quando o destino é novo, você pode corrigir o endereço e, depois da coleta, registrar se houve tip. O app aprende com o histórico. Os dados ficam armazenados neste dispositivo.
Dados armazenados neste iPhone. Nenhum print é enviado para um servidor por este app.
